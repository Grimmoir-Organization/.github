# Grimmoir Organization · Community

This repository contains the shared GitHub profile, community guidelines, issue forms, and contribution defaults used across Grimmoir Organization repositories.

> This repository defines organization-wide defaults. Individual projects may override them where project-specific requirements exist.

## Scope

These files are intentionally general because Grimmoir Organization is not restricted to one technology, field, development model, or project category.

A repository may provide its own policies whenever its requirements differ from these defaults.

## Project Authority

Repository-specific documentation takes precedence over organization-wide defaults for:

- licensing;
- attribution;
- maintainership;
- contribution requirements;
- support expectations;
- release policy;
- security scope.
