# Grimmoir Organization — GitHub Community Setup

This repository contains the organization-wide GitHub profile and default community health files for Grimmoir Organization.

## Structure

- `profile/README.md` — public organization profile
- `CONTRIBUTING.md` — default contribution guide
- `SECURITY.md` — default security policy
- `SUPPORT.md` — default support guidance
- `CODE_OF_CONDUCT.md` — organization-wide conduct policy
- `.github/ISSUE_TEMPLATE/` — default issue forms
- `.github/pull_request_template.md` — default pull request template

Individual repositories may override these defaults with their own files.
